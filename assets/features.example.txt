# 可选特性示例 —— 一般不用手编:交互终端裸跑 .\scripts\launch.ps1 start 会弹菜单自动改写
# 每行一个特性 id,`#` 起始为注释,空行忽略;删掉某行(或全注释)即全部关闭
#
# 可用特性 id(见 scripts\launch.ps1 的 $optionalFeatures):
#   tailscale   跨网络直连 VM 上的服务(公司机器别开,会被软件审计识别)
#   path-map    VM 里 Claude Code 自动把对话里的宿主机 Windows 路径换算成挂载点路径
#   clip-bridge 宿主机截图 → VM 里 Claude Code Ctrl+Shift+V 粘图,Ctrl+V 留给文本粘贴(非重建型,勾上即生效)
#   dev-java    VM 预装 JDK 17 + Maven(非重建型;离线 bundle 秒装,缺件回退在线 apt)
#   dev-python  VM 预装 python3 + uv(非重建型;离线 bundle 秒装,uv 全包 venv/依赖)
#   dev-frontend VM 预装 pnpm(非重建型;离线 bundle 优先,Node 20 已是基础件)
#
# 示例(启用 tailscale):
# tailscale
#
# 特性标记为"重建型"的(如 tailscale)需 delete + start 重建 VM 才生效;
# 交互终端下 start 会探测并询问是否立即重建。
# 非重建型的(如 path-map、clip-bridge、dev-*)勾上后现有 VM 下次 start 即生效
# 此文件放在状态目录的 VM 子目录(默认 %USERPROFILE%\.cc-sandbox\claude-dev\features.txt),不进仓库
